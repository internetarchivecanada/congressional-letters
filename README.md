# Letters from Congress

Letters that members of Congress published on their own websites, preserved by
the Wayback Machine — every Congress's explorer in one place, searchable across
all of them.

**→ <https://internetarchivecanada.github.io/congressional-letters/>**

This is the home page. Each Congress has its own explorer beside it:
`internetarchivecanada/Explorer-Congressional-Letters-106` to `-119`, served at
`internetarchivecanada.github.io/Explorer-Congressional-Letters-<N>/`.

Built output, never edited by hand. It is built from
[Congressional-Letters-Dev](https://github.com/Robin-IA/Congressional-Letters-Dev)
(`build/build_hub.py`) and published here. The letters themselves are not
stored here: every one opens from the Wayback Machine.

Until 12 November 2026 this repository held the 119th Congress explorer. That
is in this repository's history, and its old links — `?member=…`, `119th/`,
`explorer.html` — forward to the 119th Congress explorer.
